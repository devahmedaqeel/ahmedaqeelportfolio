## 🌌 Key Architectural Features

### 1. 🌐 Global Full-Page Dual-Theme Neural Background Engine
- **Full Viewport Canvas Layer**: Positioned at `z-index: 0` (`position: fixed; inset: 0; width: 100vw; height: 100vh; pointer-events: none;`).
- **Continuous Scroll Coverage**: Remains visible behind all content layers from Top (Navbar/Hero) to Bottom (Footer).
- **Dual-Theme Support**:
  - **Dark Mode**: Cyber Cyan (`#00f2fe`) & Indigo (`#818cf8`) particles on `#03050c` dark space.
  - **Light Mode**: Sky Blue (`#0284c7`) & Indigo (`#4f46e5`) particles on `#f8fafc` light slate.
- **Smooth ~400ms JS Theme Lerp**: Color transition occurs smoothly without resetting or freezing moving particles.
- **60 FPS Optimized**: Delta-time (`dt`) frame rate independent motion with fast squared-distance (`distSq`) line calculations.

### 2. 🛡️ Secure Vercel Serverless API & Nodemailer Contact Form
- **Custom Serverless Endpoint**: `/api/submit-contact` running on Node.js Serverless Functions (`nodejs20.x`).
- **Nodemailer SMTP Transporter**: Secure Google SMTP transport routing incoming inquiries directly to `engrahmedaqeel14@gmail.com`.
- **Zero Exposed Credentials**: Authentication parameters are secured via Vercel Environment Variables (`GMAIL_USER`, `GMAIL_APP_PASSWORD`, `ADMIN_EMAIL`).

### 3. 🤖 Interactive Developer CLI Shell Terminal
- Built-in terminal CLI supporting utility commands: `help`, `about`, `skills`, `projects`, `contact`, `neofetch`, `clear`, `exit`.

### 4. 📱 Fluid Mobile Responsiveness & Light Mode Stats Bar
- **Responsive Breakpoints**: Optimized across `320px`, `375px`, `390px`, `414px`, `768px`, `1024px`, `1280px`, `1920px`.
- **Mobile Stats Bar**: Displays horizontal stats row (`20+ PROJECTS` | `2+ YEARS EXP` | `5★ AVG RATING`) with vertical divider lines.
- **Status Dot Blinking**: Glowing `#10b981` status pulse active in both Light and Dark modes.
